# 乐谱生成

> 音轨 → 五线谱/吉他六线谱 → MusicXML
> 状态：🔄 VER2.0 开发中 (basic-pitch + 5 层后处理)

## 五层管线架构

```
Layer 0: 预处理     → [[bpm_detect.py]] + [[source_separate.py]]
Layer 2: 转录模型   → [[transcriber.py]] (basic-pitch / 自训模型)
Layer 3: 帧级后处理 → [[frame_post.py]] (HMM + 连通域)
Layer 4: 音符级后处理 → [[note_post.py]] (谐波过滤 + onset 精修)
Layer 5: 乐谱组装   → [[score_assemble.py]] + [[pipeline.py]] → MusicXML
```

## 推理管线模块

| 模块 | 功能 | 技术 |
|------|------|------|

| [[pipeline.py]] | 主流程编排 | 5 层串联 |
| [[key_estimate.py]] | 调号推算 | K-S 算法 24 调相关 |
| [[guitar_tab.py]] | 吉他排指 | DP 最短路径 |

## 核心技术

详见 [[技术白皮书]]

- **音高确定**: basic-pitch Onsets-and-Frames → 逐帧 88 音高概率图
- **时值确定**: 连通域标注 + HMM 平滑 → onset/offset 帧
- **音符结束**: frame_probs 低于阈值 → 标记 offset
- **多声部**: 所有音在同一 Part 中按绝对时间排列，music21 自动处理
