# 乐器识别模型研发日志

## 待突破基线：CNN (85%) -> ResNet (95%+)

### 版本: VER1.1 (过拟合反击战)
**模型结构**：
- 输入层：1 通道 / 3 通道 Mel-spectrogram
- 主干网络：PyTorch `ResNet34` (比起 1.0 的 18 更深)
- 丢弃层：最后加入两个强力组合：`Dropout(0.6) + Linear(256) + ReLU + Dropout(0.4)`，大幅压缩拟合余地

**创新点 / 尝试**：
1. 这是基于用户提供的旧有效方案的改良：由于 85% 原分类器强行采用了高达 `0.5/0.8` 的 Dropout 率制裁了过拟合，我们也在全连接部分使用了极高的失活率。
2. 数据增强（Data Augmentation）：在 `dataset.py` 中新加了随机环境频域（`FrequencyMasking=15`）和时域（`TimeMasking=15`）裁剪，以及微小的随机高斯噪音，破坏模型死记硬背样本特征。
3. 加入 `L2 权重衰减 (weight_decay=1e-3)`。
4. 挂载了 `LR_Scheduler (ReduceLROnPlateau)`，在验证 Loss 遭遇平静期 3 轮以上时自动对折下调学习率。
5. 轮次上限打开到 50 轮探索拟合边界。

**最终模型性能评价**：
- Train Loss: 最低降至 0.01 左右，训练极其充分。
- Val Loss: 一直在 2.1 左右徘徊不能下降。
- Val Acc: 经过长时间摩擦，最高只能稳定在 60.48%。

**下次修改建议/分析**：
尽管挂载了最高强度的 Dropout 和数据增强。但 1.1 版本依然陷入了过拟合和特征不举的困境（卡死在 60%）。
这是由一个**致命失误**引起的：`ResNet34` 预加载了 ImageNet 的权重，但其实那是识别 RGB（3 通道）图像的。在我们的代码中，用 `nn.Conv2d(1, 64...)` 将它的第一层强行替换成了单通道，但这**完全清空了预训练特征**并用随机数进行了初始化。这就导致整个残差网络等于在第一层输入随机噪声，被迫在仅仅区区几千张 3 秒乐器样本上从头训练了一个千万参数的 ResNet34！

### 版本: VER1.2 (跨界微调复用术 / 剑指 90%+)
**模型结构**：
- 输入层：1 通道 Mel-spectrogram
- 主干网络：PyTorch预训练 `ResNet34`
- 修复核心：**预训练权回复**。将原来 ImageNet 第一层 Conv2D (3通道) 的权重通过取平均（`weight.sum(dim=1, keepdim=True)`）或者同等复制，巧妙地塞回我们强行魔改的、接收 1 通道频谱图的第一层小卷积内核中。让网络保留原本的“边缘、纹理特征提取能力”。

**创新点 / 尝试**：
1. 修复了残差主干 `conv1` 层由于通道削减导致预训练被撕裂的问题。
2. 保持之前的高 Dropout 和 SpecAugment 保护伞不变。

**最终模型性能评价**：
- Train Loss: 最低降至 0.008 左右
- Val Loss: 一直在 1.85 ~ 1.95 波动
- Val Acc: 最终稳定在 62.6% 左右，仍然未能突破 85% 基线。

**下次修改建议/分析**：
尽管恢复了第一层权重，但由于使用了 Min-Max 归一化破坏了频谱响应比例、未引入类别均衡采样（导致严重偏置）、全连接层依然过于臃肿带有极高 Dropout(0.6/0.4) 导致严重欠拟合，以及 Adam 收敛过快等问题综合发作，模型依旧被焊死在 60% 左右。需要对这4项进行彻底回调。

### 版本: VER1.3 (回归本质：旧版特性移植重建 / 剑指超越 85%)
**模型结构**：
- 输入层：1通道提取后使用 `.repeat(3, 1, 1)` **直接伪装复制为 3 通道图**，完美适配 ResNet34 输入要求（不修改主干的 conv1）。
- 主干网络：PyTorch预训练 `ResNet34` (不破坏任何原生结构)
- 输出层：放弃臃肿的全连接结构，利用其内部自带的全局平均池化直接接 `nn.Sequential(nn.Dropout(0.3), nn.Linear(512, 11))` 的单薄分类头。

**创新点 / 尝试**：
1. **彻底修复特征撕裂**：不改主干通道数，用真实的三通道“伪彩色图”骗过网络从而100%保留 ImageNet 提取能力。
2. **底层标准化回归**：在 `dataset.py` 中将音频处理从容易受异常值暴击的 `Min-Max` 区间缩放全面换回 `Z-Score`。
3. **样本均衡采样**：引入 `WeightedRandomSampler` 来严格按样本数倒数概率抽样，强迫模型对每个乐器“一碗水端平”。
4. **更换稳定策略**：采用带 `momentum=0.9` 的 `SGD` 来替换 `Adam`，配以 `CosineAnnealingLR` 让其更好地在长距离微调中寻找最优泛化解。

### 版本: VER1.0 (已合档)
**模型结构**：
- 输入层：1 通道 / 3 通道 Mel-spectrogram
- 主干网络：PyTorch 官方预训练的 ResNet18 特征提取器（相比前版 CNN 带深层残差连接）
- 输出层：Dropout(0.5) 避免过拟合 + 11 维全连接分类器输出。

**创新点 / 尝试**：
1. 使用深层残差结构（ResNet）代替浅层 CNN 进行多乐器分类，期望泛化能力提升。
2. 更改最后的全连接结构，增加一个 Dropout。
3. 动态配置通道及超参（`in_channels=1` / `num_classes=11`）并打包保存在 `pth` 伴随字典中，方便后续的测试代码能够实现“自适应加载不脱节”。

**最终模型性能评价**：
- Train Loss: 平均降低至 0.13 左右（但产生过拟合现象）
- Val Loss: 平均在 2.3 左右，与训练 Loss 产生显著背离
- Val Acc: 最终稳定在 53% 左右
