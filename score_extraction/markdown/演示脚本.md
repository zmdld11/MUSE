# MUSE 演示脚本（Phase-1 结项 · 演示视频用）

> 目标时长 3-5 分钟。前置：`pnpm dev`（frontend/）已起，浏览器开 http://localhost:5173；
> 或直接打开 `dist/index.html`（静态包，2026-08-27 重建）。
> 演示曲：《虚無の先で愛を見つける》完整版（266s）。

## 0. 开场（30s）

- 页面空态文案一句话：**音频进，乐谱出**——分离（VER-SEP 3.0b）→ 转写（ia-amt）→ 记谱（时值 v2 代价 DP）。
- 关键词字幕：`一键流 = python run_one.py <音频> --demo`（贴终端跑一遍的录屏，4 分钟压到 10 秒）。

## 1. 卷帘播放器（60s）

- 点「加载演示曲目」→ 卷帘自动展开：7 条轨道（原声吉他/失真吉他/清音吉他/贝斯/钢琴/电钢琴/主旋律），家族配色。
- **看点 A：播的是"谱面的 MIDI"**——音符全部落在网格上（时值 v2 的单位分数占 ~85%），不是转写模型的原始毛刺输出。
- **看点 B：稀疏轨道已删**——转写原始输出里的 strings(13 音)/sax(5 音) 轨不会出现（准入线统一管谱面+播放）。
- 操作演示：mute/solo 吉他轨、Ctrl+滚轮缩放、八音盒跟随模式。

## 2. 乐谱视图（60s）

- 切到谱页：OSMD 渲染的 MusicXML，逐轨 Tab 切换。
- **看点 C：贝斯 = 低音谱表**（修复前是高音谱表挂 6 条下加线）、**吉他 = 高音谱表 8vb + 六线 TAB**（TAB 行休止符按惯例隐藏）。
- **看点 D：量化/忠实双模式切换**——量化谱干净可读（时值全部合法单值+连音链），忠实谱保留原始时值细节。
- 顶部调号（自动检测）与 AI 分析摘要。
- 播放时谱面走跟随光标（与卷帘同时间轴）。

## 3. 音轨与源音频对照（45s）

- 播放源切「原曲/谱面 MIDI/混合」三态：原曲伴奏下听分离出的吉他声部（VER-SEP 3.0b，F2' 真实域 note@50 0.7399）。
- 说明：卷帘时序与原曲对齐（time-truth = 原曲时间轴）。

## 4. 收尾数字（30s）

- 一张表：F2' 真实域 42 对三臂（off 0.644 / v11 0.734 / **v30b 0.740**）；时值单位分数占比 85%；回归门 8 文件 0 问题。
- 结束语：数据工厂路线（音色轴×伪影轴）的 Phase-1 落地。
