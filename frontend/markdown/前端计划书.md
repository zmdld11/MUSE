# MUSE 桌面端前端计划书

- 版本：v1.0（2026-08-22）
- 状态：选型已定案，待脚手架启动
- 工程位置：仓库根目录 `frontend/`（注意：不是 `muse/frontend`，工作区实际在根目录，内含空的 `markdown/` 与 `src/`）
- 已定案选型：**Tauri 2 + React 18 + TypeScript + Vite + Tailwind v4 + shadcn/ui + zustand + Canvas 2D 卷帘 + Python sidecar（阶段二）**

---

## 1. 目标与范围

桌面端优先，网页版列入远期路线（§11）。应用分两大模块：

1. **钢琴卷帘播放器**（仿 bilibili av116979826497523 演示软件）：
   - 顶部控制区：播放/暂停、快进/回退、上一首/下一首、倍速；
   - 左栏乐器标签：按乐器列出音轨，可选中乐器；
   - 中央主题区：钢琴卷帘，音符块按乐器分色。
2. **乐谱展示页**：与播放器联动，可在卷帘↔乐谱间切换，乐谱上有移动光标指示播放位置。**本期只做占位空页面**，等记谱规则讨论完成后填充。

本期明确不做：
- 转写管线集成（Python sidecar，阶段二，本计划书只定接口契约）；
- 按乐器分轨试听（stem 播放/合成器，远期）；
- 乐谱实际渲染（等记谱模块定案）。

## 2. 技术选型定案及理由

| 层 | 选择 | 理由 |
|---|---|---|
| 桌面壳 | **Tauri 2** | Rust 壳 + 系统 WebView2：装包 3~10MB、内存占用最低；Windows 11 亚克力/Mica 窗口材质是内置配置；官方拖拽/文件/对话框插件齐全。本机前置仅缺 rustup（一次性安装）。否决项：Electron（~200MB、空载 150MB+，上一代方案）；pywebview（无内置亚克力/Mica，生态最小） |
| UI 框架 | **React 18 + TypeScript** | 生态最大，shadcn/工具链齐全，将来网页版直接复用 |
| 构建 | **Vite** | Tauri 官方推荐组合，HMR 快 |
| 组件库 | **Tailwind v4 + shadcn/ui** | 组件源码拷进项目自由定制，设计自由度和资料最多；UWP 质感靠设计规范（§4）+ 自调亚克力面板实现 |
| 状态管理 | **zustand** | 轻量、无样板代码、切片式 store 契合分层架构 |
| 卷帘渲染 | **Canvas 2D 自绘 + requestAnimationFrame** | 每帧重绘的东西必须绕开 React（见 §8）；万级音符 Canvas 2D 足够，将来不够再升 PixiJS(WebGL) |
| MIDI 解析 | **@tonejs/midi** | 纯 JS 解析 Standard MIDI File，MVP 直接吃管线 `.mid` 产物 |
| 音频播放 | **Web Audio API** | AudioContext + AudioBufferSourceNode；倍速用 playbackRate，精确定位与卷帘同步靠 AudioContext.currentTime 时钟 |
| 后端服务 | **Python sidecar（FastAPI + localhost）** | 阶段二；复用 `score_extraction` 管线，HTTP+JSON 边界 |

本机工具链现状（2026-08-22 已核验）：node v24.13.1 / npm 11.8.0 / pnpm 10.30.1 / MSVC 2022（VS Community + BuildTools）/ WebView2 151.x **均已就绪**；**rust/cargo 未装**，M1 第一步由我安装 rustup。

## 3. 架构说明

### 3.1 分层架构（FSD-lite 六层）

```
app → pages → widgets → features → entities → shared
（依赖只许从上往下 import，禁止反向 —— 整个工程是一张 DAG，出现环就是架构腐烂的开始）
```

| 层 | 职责 | 本项目首批成员 |
|---|---|---|
| app | 应用壳：挂载、全局 Provider、窗口初始化 | main.tsx、App.tsx、路由 |
| pages | 页面级组装 | player 播放器页、score 乐谱页（占位） |
| widgets | 页面内大块组合件 | TransportBar、InstrumentPanel、PianoRoll、Playlist |
| features | 业务能力（含状态） | playback、library、transcription(阶段二) |
| entities | 领域模型与 store 切片 | Note / Track / Project 类型与 zustand store |
| shared | 无业务依赖的底层 | UI 原子组件、hooks、utils、theme tokens |

纪律：UI 只"发起意图"不改数据；状态变了 UI 自动重画（单向数据流）。

### 3.2 进程模型（三进程三种语言，接口即边界）

```
┌─────────────────────┐  事件/命令   ┌──────────────────┐
│  React UI (WebView) │ ───────────▶ │  Rust 壳 (Tauri)  │
│  界面渲染/交互        │ ◀─────────── │  窗口/亚克力/拖拽/  │
└─────────┬───────────┘   文件路径等   │  文件对话框/sidecar │
          │ HTTP + JSON (localhost, 阶段二)  │ 启动管理
          ▼                              └────────┬─────────┘
┌─────────────────────┐                       ▼
│  Python 核心服务      │ ← FastAPI sidecar，import score_extraction 管线
│  转写/分离/记谱       │
└─────────────────────┘
```

- 互不共享内存，谁崩都不连坐；
- **网页版迁移 = 把 React 层原样搬进浏览器，换掉壳**——所有 Tauri 专属调用收敛在 features 层的适配器里，不允许散落在组件中。

### 4.5 字体

- 界面：`"Segoe UI Variable Text", "Segoe UI", system-ui`（Win11 系统 UWP 同款，零加载成本）；
- 标题：`"Segoe UI Variable Display"`；
- 时间码：等宽数字——`font-variant-numeric: tabular-nums` 或 `"Cascadia Mono"`。

### 4.6 动画原则

- 时长 150~250ms，减速曲线（`cubic-bezier(0.16, 1, 0.3, 1)` 出场类），退场比进场快；
- 动画必须传达含义（视图切换的空间连续性、按钮按下反馈），不做纯装饰动画；
- 尊重 `prefers-reduced-motion`，开启时降级为瞬时切换；
- **播放头不走 CSS/React**——Canvas 内 rAF 绘制（§8）；
- 性能红线：不动画 `width/height/top/left`，只动画 `transform/opacity`。

### 4.7 可访问性底线

- 文本对比度 ≥ 4.5:1（深色 token 已按此设计，`--text-3` 仅用于非关键装饰性文字）；
- 图标按钮必须带 tooltip + `aria-label`（播放器大量纯图标按钮，这条是硬要求）；
- 全键盘可达：空格=播放暂停、←/→=±5s、PgUp/PgDn=切歌、↑/↓=音量。

## 6. 数据契约

### 6.1 MVP（M1）：吃管线现有产物

数据源 = 打开**管线输出目录**（如 `score_extraction/output/05_kyomu_vocal/`）：

```
05_kyomu_vocal/
├─ 05_kyomu_vocal.flac（或同名音频，前端在目录/上级目录自动关联）
├─ guitar.mid          ← @tonejs/midi 解析 → notes
├─ guitar.musicxml     ← 本期不用（乐谱页占位）
└─ info.json           ← {"song": "...", "bpm": 80.7, "time_signature": "4/4"}
```

MIDI 字段映射：`note.time → onset`、`note.time + note.duration → offset`、`note.midi → pitch`、`note.velocity → velocity`；乐器色由 MIDI program → GM 音色 → §6.3 族映射（简化表：GM 128 音色 → 10 族）。

### 6.2 阶段二：notes.json 落盘 + sidecar API

管线侧新增 `notes.json` 导出（字段与内存 note dict 一致），schema：

```jsonc
{
  "schema_version": 1,
  "song": "05_kyomu_vocal",
  "bpm": 80.7,
  "time_signature": "4/4",
  "duration": 213.4,
  "source": { "audio": "path", "frontend": "ia_amt:guitar_v1_5", "separated": false },
  "tracks": [{
    "instrument_class": "distorted_guitar",   // 36 类字符串名
    "display_name": "失真吉他",
    "notes": [{
      "onset": 1.234,        // 秒
      "offset": 1.876,       // 秒
      "pitch": 64,           // MIDI 音高
      "velocity": 100,       // 1-127
      "confidence": 1.0,     // ⚠ ia-amt 恒 1.0，UI 不可当真实置信度用
      "string": 6, "fret": 0 // 吉他线专有（6=低E弦…1=高E弦）
    }],
    "pedal_events": [{ "onset": 0.0, "offset": 2.5 }]  // 钢琴线专有
  }]
}
```

sidecar（FastAPI，localhost 随机端口，Tauri 负责启动/回收）：

```
GET  /api/status              → {"app":"muse-core","version":"0.1.0","device":"cuda",
                                 "models":{"ia_amt":"loaded","bytedance":"missing"},"busy":false}
POST /api/transcribe          {"audio_path":"...","options":{"guitar_frontend":"ia_amt","separate":false}}
                              → 202 {"job_id":"j_..."}        （转写耗时长，必须异步任务）
GET  /api/jobs/{job_id}       → {"state":"queued|running|done|error","progress":0.42,
                                 "stage":"separation|transcription|notation",
                                 "result":{"output_dir":"...","notes_json":"..."}}
POST /api/jobs/{job_id}/cancel
```

## 7. 交互细节清单

| 场景 | 行为 |
|---|---|
| 单文件打开 | 文件对话框选择音频 → 单曲模式（上一首/下一首禁用置灰） |
| 文件夹打开 | 递归扫描，扩展名白名单 `wav/flac/mp3/ogg/m4a/aac`，非音频跳过；扫描结果进播放列表（排序按文件名自然序） |
| 拖入单个音频文件 | 等同单文件打开 |
| 拖入多个文件 | 创建临时播放列表（应用缓存目录 `app_cache/playlist_<ts>/`），**退出时清理** |
| 拖入实现方式 | Tauri webview 级拖拽事件（`onDragDropEvent`，注意 Tauri 默认关闭 HTML5 DnD，`dragDropEnabled` 保持默认走 Tauri 通道） |
| 打开管线输出目录 | 目录含 `*.mid + info.json` 时自动关联同名音频，进入"转写结果浏览"模式（卷帘有数据可画） |
| 上一首/下一首 | 播放列表内切换；列表尾/头循环策略：列表循环（远期可加选项） |
| 倍速 | 档位 0.5/0.75/1.0/1.25/1.5/2.0，下拉选择；playbackRate 实现，卷帘时间轴同步 |
| 快进/回退 | ±5s 按钮 + ←/→ 键 |
| 乐器静音/独奏 | 左栏每轨 mute/solo 图标；**本期仅显示层**（卷帘过滤显隐），分轨音频远期 |
| 视图切换 | 顶栏右侧"卷帘 \| 乐谱"分段控件，切换带 200ms 空间过渡动画；乐谱页本期为占位 |
| 播放结束 | 自动下一首（有列表时）/ 停在末尾（单曲时） |

## 8. 性能原则

1. **卷帘虚拟化**：只绘制可视时间窗 ± 一屏缓冲的音符，滚动时增量绘制；
2. **播放头不进 React**：rAF 循环读 `AudioContext.currentTime` 直接画在 Canvas 覆盖层，React 状态里只存秒级粗粒度时间（供时间码显示，250ms 节流更新）；
3. **双缓冲**：静态音符层（滚动/缩放才重绘，可离屏 Canvas 缓存）+ 动态层（播放头/选中高亮）分离；
4. `devicePixelRatio` 适配，避免高分屏模糊；
5. 音频解码放 Worker，长曲子给进度反馈（decodeAudioData 内存约 20MB/分钟，10 分钟曲子可接受，更长再考虑流式方案）;
6. 列表/面板类组件 `React.memo`，store 用 selector 订阅最小切片。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| rustup 下载失败（网络） | 无法编译 Tauri | 我先尝试静默安装；失败请用户手动装 rustup-init.exe |
| WebView2 与标准 Chromium 的 CSS 差异 | 材质/动画效果打折 | 窗口级材质交给 Tauri（系统合成器）不依赖 CSS；面板级 backdrop-filter 渐进增强 |
| 全局 `lib/`、`dist/` gitignore 规则误伤前端目录 | shadcn 工具文件/构建产物不进版本库 | shadcn 别名用 `utils/` 不用 `lib/`；.gitignore 加防护白名单（已随本计划书落地） |
| Tauri 默认禁用 HTML5 拖放 | 拖拽失灵 | 统一走 Tauri `onDragDropEvent` |
| 长音频解码内存/耗时 | 大文件卡 UI | Worker 解码 + 进度条；必要时降采样 |
| 超长曲子卷帘渲染 | 掉帧 | §8 虚拟化 + 双缓冲 |
| ia-amt `confidence` 恒 1.0 | 置信度可视化无意义 | M1~M4 不做置信度 UI；阶段二评估模型侧补真实分数 |
| sidecar 占 GPU | 播放时转写卡顿（阶段二） | 任务队列串行；播放中提醒 |
