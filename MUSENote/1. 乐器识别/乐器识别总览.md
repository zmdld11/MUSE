# 乐器识别

> 识别音频中任意时刻出现的乐器，输出时间轴概率热力图
> 状态：✅ 已完成 (VER4.0_BinaryEnsemble)

## 模型架构

```
音频 (22050 Hz, 3s 片段)
    ↓
Mel 频谱 + MFCC + ModGD phase 特征
    ↓
CNN Encoder → Transformer → 多标签分类
    ↓
10 类乐器概率: acoustic guitar, cello, drum set, electric bass,
              electric guitar, flute, piano, singer, synthesizer, violin
    ↓
时间轴拼接 → 全曲热力图
```

## 关键模块

| 模块 | 功能 |
|------|------|
| `config.py` | 全局配置 (SR=22050, 10 classes) |
| `dataset.py` | MedleyDB 数据加载 + 预处理缓存 |
| `btrain.py` | 训练脚本 |
| `bmodel.py` | CNN+Transformer 模型定义 |
| `binfer_cli.py` | 命令行推理入口 |
| `beval.py` | 评估脚本 |
| `finetune_all.py` | 全量微调 |

## 训练数据

- **MedleyDB**: 多乐器分离音轨 (MAX_STEMS_PER_CLASS=10)
- **IRMAS**: 原始多标签数据 (已弃用，换 MedleyDB)
- 数据增强: mixup, time shift, pitch shift
- 特征缓存: `data/preprocessed_cache/`
