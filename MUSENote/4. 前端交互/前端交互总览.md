# 前端交互

> Vue3 用户界面 — 未启动

## 计划架构

```
Vue 3 + Vite + vue-router
    ├── HomeView        — 首页
    ├── DashboardView   — 数据看板
    ├── ServiceView     — 服务页 (三个模型入口)
    └── AboutView       — 关于
```

## 三大功能入口

1. **乐器识别** → 调用 [[1. 乐器识别]] 的 [[binfer_cli]]
2. **音轨分离** → 调用 [[htdemucs_6s]]
3. **乐谱生成** → 调用 [[pipeline.py]]

## 技术要求

- 路由懒加载 ()=>import(...)
- Intersection Observer 入场动画
- scroll 事件 throttle 200ms
- 动画仅用 transform + opacity
- 图片 WebP + lazy loading
