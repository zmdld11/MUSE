# MUSE (Music Unmixing & Score Extraction System) 项目说明（本地版）

## 1. 项目简介
本项目（MUSE）旨在提供一套集成了**乐器识别**、**音轨分离**以及**乐谱生成**的完整音频处理管线。
当前主要目标是对吉他音轨进行精准的高级分离和转换，同时利用乐器识别辅助提升整体性能。

## 2. 工作区结构
项目采用 Monorepo 方式管理：
- `data/`：共享数据集目录（IRMAS、nsynth、MedleyDB、moisesdb_v0.1 等）。不在版本控制内。
- `music/`：供本地测试用的完整首曲文件夹（不可上传 Git）。
- `instrument_recognition/`：乐器分类模型工作区，基于 PyTorch 和 Librosa 提取 Mel 频谱图。
- `source_separation/`：音轨分离工作区，未来将引入时域或频域的分离网络（如类 Demucs 架构）。
- `score_extraction/`：扒谱及 MIDI 生成模型工作区（主要从已分离的音轨中获取）。
- `frontend/`：用户界面系统。

## 3. 开发规范
每次模型迭代，务必在对应子项目的 `markdown/model_log.md` 中说明创新点与版本号。最高分的检查点始终保存为 `model/best_model.pth` 并通过自适应测试代码实现校验。

## 4. 环境推荐
由于该项目严重依赖 GPU，推荐通过 conda 在根目录独立创建：
```bash
conda create -p ./env python=3.10
conda activate ./env
conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia
pip install librosa numpy pandas tqdm matplotlib soundfile
```

## 本机环境

**本机：**INTEL core I9-14900HX + NVIDIA 4060 LAPTOP 8GB + 64GB RAM + 4T SSD

**AutoDL：**由于预算受限，GPU最高可选5090 32GB

**数据集：**均来源于网络

1. IRMAS-TrainingData（混轨数据集，用来训练最初版本的乐器识别模型）
2. nsynth（分轨数据集，提供了每种乐器的单音，试验下来不能进行模型训练，但是可以生成MIDI音频）
3. MedleyDB（分轨数据集，有每个乐曲的分轨音频，可用来训练分轨模型）
4. moisesdb_v0.1（同上）
